# slicerweb-app

The published [SlicerWeb](https://github.com/lassoan/SlicerWeb) application:
<https://lassoan.github.io/slicerweb-app/>

Every file here is built, and this repository holds one build and no history - each build
replaces the last one. Nothing here is edited by hand; the source is in the SlicerWeb
repository, and the build is `.github/workflows/publish-app.yml` there.
